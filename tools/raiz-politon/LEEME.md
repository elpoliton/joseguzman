# Atajo politon.pe/paginas

Esta carpeta **no se publica** (está en `tools/`). La cuenta FTP del repo solo llega a politon.pe/joseguzman.
Para que politon.pe/paginas lleve a «Mis páginas», José sube una sola vez `paginas/index.html`
a la carpeta raíz de politon.pe (la que tiene el `index.html` de la empresa), dentro de una carpeta nueva llamada `paginas`, desde el administrador de archivos del cPanel.
No hay que volver a subirlo: la lista de páginas se edita en `assets/paginas.js`.
