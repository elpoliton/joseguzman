¿Cómo creo mi llave? (una sola vez)
  1. Entra a github.com/settings/personal-access-tokens/new.
  2. Token name: Panel joseguzman · Expiration: 1 año.
  3. Repository access: Only select repositories → elpoliton/joseguzman.
  4. Permissions → Repository permissions: Contents: Read and write · Actions: Read-only.
  5. Pulsa Generate token, copia la llave y pégala aquí. No la compartas con nadie.
